# 研究設計の批判的再検討 — 2026-06-26

> **このドキュメントの目的:** セッション横断で同じ間違いを繰り返さないための「確定した見解」の記録。
> 「kawaii二次元が一番」という仮説の検証研究として出発したが、複数回の批判的分析を経て
> 研究設計に根本的な問題があることが判明した。以下にその全容と推奨設計を記す。

---

## 1. 研究の出発点と発見されたギャップ

### 当初のRQ（問題あり）
「LLMで中身が同等のとき、AIコンパニオンの身体の様式（テキスト/写実人型/二次元・可愛い）は
ユーザーの親密度・自己開示・継続利用意図をどう変えるか」

### 先行研究調査で判明した重要事実
- 「身体があると親しまれる」はPersona Effect(1997)以来の既確立命題 → **そのままでは新規性なし**
- 「どの様式が最適か」を直接問うFrontiers 2026論文が先行して存在するが、**30秒動画の初見評価であり実際の会話ではない**
- **「中身を完全固定して様式だけを操作した縦断研究」は現時点で存在しない** ← これが本物のギャップ
- ただし「存在しない」には理由がある（下記）

### なぜその研究が存在しないのか（2つの障壁）
1. **視覚だけ変えると品質が非対称になる**: リアル3Dモデルは微細なモーションが必要。同じモーションリグで「様式だけ」を変えると、リアル側に不自然さが生じ、「不気味の谷からくる嫌悪感」と「被評価感からくる自己開示抑制」を切り分けられなくなる。
2. **LLMの縦断制御が難しい**: 会話文脈が条件間で分岐し、LLMの出力ブレを様式効果から分離できない。

## 2. 未解決の交絡変数（全リスト）

### A. 音声の問題（最重要・ユーザー指摘）

**現状:** Aivis Speechは「アニメ声」寄りであり、全条件で同じTTSを使うと以下の問題が生じる。

| 条件 | 視覚 | 音声（現状） | 問題 |
|------|------|------------|------|
| テキスト | なし | アニメ声 | 「テキスト条件」なのに声がkawaii印象を作る |
| 写実 | リアルVRM | アニメ声 | 視覚と音声のミスマッチ → 不快感の原因が特定不能 |
| kawaii | Shiro.vrm | アニメ声 | 内部的に一貫 |

**選択肢と評価:**

| 選択肢 | 内容 | 問題 |
|--------|------|------|
| A: 条件ごとに声を変える | kawaii=アニメ声, 写実=中性TTS, text=なし | 声と視覚が同時に変わる → 2変数が共変 |
| B: 全条件を中性TTSに統一 | 視覚のみ変える | kawaii条件が実態と乖離（シロに中性声は不自然）|
| C: 全条件を無音に | 純視覚比較 | エコロジカル妥当性ゼロ |
| **D: 「ホリスティック条件」として設計** | 声+視覚をパッケージで操作 | 「視覚の効果」は言えなくなるが「キャラクター体験パッケージ」の比較になる |

**推奨: 選択肢D（ホリスティック条件設計）**

Frontiers 2026論文もこの方法（"holistic character conditions"）を採用して査読を通過している。
RQを「視覚様式が自己開示を変えるか」から**「キャラクター体験様式が自己開示を変えるか」**に変える。
これはエコロジカル妥当性が高く、プロダクト設計への示唆も明確になる。

```
条件A（kawaii）  : Shiro.vrm + Aivis アニメ声（現行v-mate体験）
条件B（realistic）: 品質同等のリアルVRM + 中性/成熟した音声TTS
条件C（text）    : アバターなし + 最小限のテキストUI + 音声なしorニュートラルTTS
```

### B. アニメーション品質の非対称（重大）

Shiro.vrmには以下のチューニングが施されている。リアル条件VRMには**これらが一切ない**。

- スプリングボーン73関節（髪・フード・しっぽ）
- 実行時カプセルコライダー（貫通対策）
- ACESトーンマッピング + リムライト
- コンタクトシャドウ
- VAD感度・TTS先読みパイプライン最適化
- 表情マッピング（感情タグ→VRM表情）の調整
- まばたき・視線・呼吸のチューニング

**もし品質が非対称なまま実験を走らせると:**
「kawaii条件の効果」が出ても、それが「kawaiiという様式の効果」なのか
「Shiroが単純によく作られているという効果」なのか判別不能。

### C. リアルVRM自体の未解決問題

- `realistic.vrm` は 53MB → Cloudflare資産上限25MB超で本番デプロイから除外済み
- 本番で一度も実際のユーザーに使われていない（未検証）
- 表情・リップシンク・モーション互換性が未確認

## 3. 「正確なデータが取れるか」の正直な評価

### 行動指標（ログ自動収集）

| 指標 | 信頼性 | 注意点 |
|------|--------|--------|
| セッション数・再訪率 | ✅ 高い | 「継続利用」の最良の指標 |
| 会話時間 | ✅ 高い | アイドル時間との分離が必要 |
| 文字数/メッセージ数 | ⚠️ 中程度 | テキスト条件は視覚がない分、言葉で補おうとして字数が増える可能性 |
| センシティブ話題数 | ⚠️ 中程度 | 話題に触れること ≠ 深い開示。分類基準を事前定義必須 |

### アンケート指標

| 指標 | 推奨尺度 | 注意点 |
|------|---------|--------|
| 自己開示 | RSDQ（改訂版自己開示尺度）または Jourard(1971)系 | 日本語版の妥当性確認が必要 |
| 社会的存在感 | Slater-Usoh-Steed (SUS) またはWitmer-Singer | 日本語適応版あり |
| 被評価感 | **標準化された日本語HCI尺度が存在しない** | 独自に項目作成 or 社会不安尺度から転用 |
| 親密度 | IOS（Inclusion of Other in Self）スケール | 単純・信頼性高い |

### 構造的な測定問題（解決困難）

1. **行動指標とアンケートが矛盾した場合に何を優先するか、事前に決めておく必要がある**
2. 短いメッセージ = 「慣れ親しんで気軽」か「飽きた」か区別できない
3. 脱落が条件依存（テキスト条件は退屈で脱落率が高い可能性）→ コンプライアーのみの分析が必要

### 脱落問題（縦断研究の最大の脅威）

条件ごとに脱落理由が異なると、「条件効果」と「脱落パターンの差」が混同される。
対策として事前に登録して、脱落者の特性（年齢・動機・初回印象スコア）を収集しておくことが必須。

→ **ルール:** 様式変更の際は視覚・音声・モーション・UIを全てリストアップして各々の制御状態を確認する。

## 9. 仮説の根本的修正（2026-06-27）

### 旧仮説が抱えていた問題

当初の仮説はこうだった：

> H1: kawaii条件 > テキスト条件 で自己開示・親密度が高くなる

しかし**arXiv 2503（N=981 の4週間縦断RCT）が反直観的な結果を出している**：

> **テキスト条件 > 音声条件 で自己開示が有意に高かった**（problem-sharing 17.13%, support-seeking 15.78%）

この発見は単なる外れ値ではない。N=981で4週間の最大規模縦断RCTが出した結果であり、無視できない。

### なぜテキストで自己開示が増えるのか ― 「二力の拮抗モデル」

kawaii条件とテキスト条件を比較するとき、2つの対立する力が働く：

```
kawaii体験パッケージ（視覚+声）によって生じる力:

  ↑ 社会的存在感 (Social Presence)
    「誰かが本当にそこにいる」感覚 → 話したくなる → 自己開示を促進

  ↑ 被評価感 (Evaluation Apprehension)
    「見られている・聞かれている」感覚 → 恥ずかしい・判断される → 自己開示を抑制
```

この2つの力がどちらを上回るかで結果が変わる：

- **社会的存在感 > 被評価感** → kawaii > テキスト（当初の仮説通り）
- **被評価感 > 社会的存在感** → kawaii < テキスト（arXiv 2503の結果）

旧H1は「kawaii > テキスト」という**方向の予測**に終始していたが、本当に問いたいのは**「この拮抗関係のどちらが勝つか、そしてなぜか」**である。

さらにFrontiers 2026は**ジェンダーが強い調整変数**であることを示している：
- 女性参加者: 2D Animeで親密度が高い（M=4.32 vs M=3.38 for 3D Cartoon）
- 男性参加者: Highly Humanoidでパッションが高い（M=5.35）

性別構成によって結果が逆転しうる。

### 修正後の仮説体系

**RQ（修正版）:**
> 同一LLMバックエンドの下で、kawaii体験パッケージ（2D kawaii視覚+アニメ声）とテキストのみの条件は、実際のAI会話における自己開示の質・社会的存在感・被評価感においてどのように異なり、それらの関係はどのような媒介構造をとるか。

**H1 ― 社会的存在感（Social Presence）**

> kawaii条件はテキスト条件より社会的存在感が高い

→ **強く支持される可能性が高い**。視覚・音声による「存在の具現化」の効果はPersona Effectから一貫して確立されている。測定することで効果量の基準値を得られる。

**H2 ― 被評価感（Evaluation Apprehension）**

> kawaii条件はテキスト条件より被評価感が高い

→ 新規の仮説。既存の社会不安・自己呈示文献からは支持されるが、HCI文脈では直接検証されていない。これが論文の独自貢献になりうる。

**H3 ― 自己開示（Self-Disclosure）― 方向を予測しない**

> 社会的存在感と被評価感の両方が自己開示の媒介変数として機能する（方向は探索的）

→ **方向を事前に固定しない**のが正直な設計。kawaii条件で自己開示が増えても減っても、H1とH2を通じた媒介モデルで説明できれば研究成立。結果が予測と逆でも「被評価感が勝った」という解釈で一貫する。

**H4 ― 継続利用**

> kawaii条件はテキスト条件より再訪率・セッション継続時間が高い（自己開示とは独立して）

→ 社会的存在感が高い条件は「また話したい」動機を生むという仮説。自己開示と継続利用が解離することも十分ありうる（楽しいが浅い話 vs 深いが重い話）。

## 10. 検証内容の方向性と手段（修正版）

### 検証の核心

この研究が明らかにしたいのは以下の一点に集約される：

> **「同一AIが話しているのに、姿と声の違いだけで、人間の開示行動と継続行動は変わるか。変わるとしたらどの心理プロセスを通じてか。」**

「kawaii が勝つかどうか」は副次的な問いであり、メカニズムの解明が主軸。

### 確定した研究設計

**条件数: 2条件（3条件は現時点で品質同等化が未解決のため見送り）**

```
条件A (kawaii): Shiro.vrm + Aivis アニメ声（現行v-mate体験）
条件B (text):   アバターなし + 音声なし + テキストUI

バックエンド: 同一Geminiモデル、同一システムプロンプト、同一メモリロジック
割り当て:    参加者間（between-subjects）— 汚染防止のため必須
```

**測定変数の設計**

| 変数 | 分類 | 測定手段 | タイミング |
|------|------|---------|-----------|
| 社会的存在感 | 媒介変数 | SUS（Slater-Usoh-Steed, 日本語版） | セッション後アンケート |
| 被評価感 | 媒介変数 | 独自4項目（「キャラクターに評価されている気がした」等） | セッション後アンケート |
| 自己開示の深さ | 主要DV | 会話ログの感情語比率・センシティブ話題割合 | ログ自動集計 |
| 自己開示の量 | 副次DV | 1ターンあたり平均文字数 | ログ自動集計 |
| 継続意図 | DV | 「また使いたい」1項目 + 実際の再訪率 | アンケート + ログ |
| 初回印象 | 統制確認 | 「見た目が好きか」1項目 | セッション開始直後 |
| デマンド特性確認 | 操作チェック | 「この実験で何を調べていると思うか」自由記述 | セッション後 |

**センシティブ話題の分類基準（事前定義必須）**

以下のカテゴリに該当するユーザー発話を「深い自己開示」とカウントする：
- 家族・人間関係の悩み
- 将来への不安・進路
- 失敗体験・後悔
- 身体・健康に関する個人情報
- 恋愛・性格の弱点

分類は2名の独立評価者が実施し、Cohen's κ > 0.7 を品質基準とする。

### サンプル・規模

| 設計要素 | 推奨値 | 根拠 |
|---------|-------|------|
| N（合計） | 40人（各20人） | 中程度効果量 d=0.6 を検出するための最低ライン（α=.05, β=.20） |
| 1セッション長 | 30分（自由会話） | PMC研究（30ターン）・Oxford研究の基準 |
| セッション数 | 1回（単一セッション）または2-3回 | IRB・募集コスト次第で決定 |
| 性別記録 | 必須 | Frontiers 2026でジェンダー × 条件の交互作用が確認されているため |

### 分析計画（事前登録推奨）

**主要分析: 媒介モデル（Process Macro Model 4 または SEM）**

```
条件（0=text, 1=kawaii）
  → 社会的存在感 → 自己開示の深さ（α→β₁経路）
  → 被評価感 → 自己開示の深さ（α'→β₂経路）
```

- 直接効果（条件→自己開示）と間接効果（条件→媒介→自己開示）を分離して報告
- Bootstrap法（5000回）で信頼区間を算出
- N=40では媒介分析のパワーが低いため、結果の解釈を「予備的」と明記する

**副次分析: 継続利用の検討**

- 条件 × 自己開示量 の相関（継続利用との独立性を確認）
- 被評価感が高い参加者でも再訪率が高いかを探索的に分析

### 解釈の枠組み（結果がどう出ても成立させる）

| 結果パターン | 解釈 |
|-----------|------|
| kawaii > text で自己開示↑ + 被評価感低い | 社会的存在感が優勢。「存在の具現化」が開示を引き出す |
| kawaii < text で自己開示↓ + 被評価感高い | 被評価感が優勢。視覚的キャラクターが「見られている」感を作る |
| 自己開示は差なし + 被評価感 kawaii > text + 継続利用 kawaii > text | 開示は抑制されるが、それでも「関わりたい」動機を生む |
| H2（被評価感）が有意でない | 被評価感メカニズムが kawaii-AI に適用できない → 社会的存在感一元モデルに帰着 |

## 11. 残存する批判的懸念（解決困難）

### 懸念①: 「自己開示の深さ」の操作化が難しい

ログから自動判定する「センシティブ話題」の分類は、**何が「深い開示」かという理論的定義と乖離しやすい**。定義を先に文書化し、評価者に渡す前にロックしなければ、結果を見てから分類基準を変えるという誘惑が生じる（Researcher Degrees of Freedom）。

対策: 事前登録（OSF等）でセンシティブ話題カテゴリと分類手順を公開してからデータ収集を開始する。

### 懸念②: 単一セッションでは「慣れ」が測れない

Frontiers 2026は30秒動画、PMC研究は30ターン（7〜10分）、どちらも初見反応しか測っていない。Oxford研究の縦断結果によれば、自己開示の軌跡は個人によって「増加型」「減少型」「安定型」「波動型」の4パターンがある。単一セッションではどのパターンに乗っているかが分からない。

対策: 可能であれば2回目セッション（1週間後）を設けて最低限の軌跡変化を捉える。それが無理なら「初期反応の研究」と明示して限界として論じる。

### 懸念③: N=40 では媒介分析の統計的パワーが低い

媒介効果の検出には単純な群間差より多くのサンプルが必要。N=40（各20人）では媒介分析がアンダーパワー。

対策: 「探索的研究・予備研究（pilot study）」として位置づけ、効果量の推定と仮説の洗練を目的とする。N=40でも「媒介の方向性の確認」は可能。
