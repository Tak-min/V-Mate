# Vision: ボタンの視認性・機能の分かりやすさ改善 (2026-06-24)

## ユーザー要望
「より視覚的にボタンがそれぞれどこにあってどのような機能を持っているかをわかりやすく改善する」。
過去フィードバック「ミニマルすぎて逆に人間味が薄い」も踏まえ、**明示的で分かりやすい方向**へ。

## 対象(iOSアプリ ios/VMate/Sources/Views)
現状のボタン(すべてアイコンのみ・ラベル無し・タップ可能に見える背景無し):
- `RootView.swift` header 右上3つ:
  1. マイク(`toggleHandsFree`)= ハンズフリー音声会話 off⇄listening。状態でアイコン4種変化
  2. スピーカー(`toggleVoice`)= シロの声(TTS)のON/OFF
  3. 日記(`book.closed.fill`)= 日記シートを開く
- `ConversationOverlay.swift` 下部:
  4. 直近メッセージカード(タップで全履歴展開、chevron.up のヒントあり)
  5. テキスト入力 + 送信ボタン(`paperplane.fill`)

## 問題点
- 3つの丸アイコンが白一色・同サイズ・無背景で「ボタンに見えない/区別がつかない/機能不明」。
- マイクのモード(聞き取り中/思考中/発話中)が色とアイコンだけで、初見では意味が読めない。
- スピーカーが「誰の声をミュートするのか」分からない。

## 改善方針(このループで作る)
1. **各ヘッダーボタンにアイコン+短いテキストラベルを併記**(例: 音声会話 / シロの声 / 日記)。
   タブバー的に縦積み(アイコン上・ラベル下、`.caption2`)。
2. **タップ可能な視覚的アフォーダンス**: 各ボタンに丸/角丸の半透明チップ背景を付け、押せると分かる形に。
3. **状態の可視化**: アクティブ時(音声会話ON/シロの声ON)はアクセントカラーで塗り、OFFは控えめなグレー。
   マイクは現在モードのラベルも動的に(聞き取り中/考え中/お話し中)。
4. **送信ボタン**も無効時/有効時のコントラストを上げ、押せる状態が一目で分かるように。
5. 既存のレイアウト(アバターが主役・上ヘッダー/下オーバーレイ)とAmbientBackground/blur基調は維持。
   色は既存のアクセントカラー・白基調に合わせ、過度に派手にしない。
6. アクセシビリティラベル(`.accessibilityLabel`)も各ボタンに付与。

## Definition of Done(停止条件)
- [ ] 3つのヘッダーボタンが「アイコン+ラベル+押せる背景+状態色」で表示され、機能が一目で分かる。
- [ ] 送信ボタンの有効/無効状態が視覚的に明確。
- [ ] **シミュレータ起動→スクリーンショットで実際の見た目を確認**し、ボタンの位置・機能・状態が
      視覚的に判別できることを目視確認(このループの主要verify)。
- [ ] `xcodebuild build`(simulator)が成功、既存`xcodebuild test`(VMateTests)が緑のまま。
- [ ] typescript-reviewer不要(iOS)。swift-reviewer/code-reviewerでCRITICAL/HIGHゼロ。
- [ ] 実機(iPhone 15 Pro)へ書き込んで最終確認、commit/push。

## ガードレール
- 機能(送信/音声/日記/履歴)の挙動は変えない。**見た目とラベルとアフォーダンスのみ**改善。
- 既存の状態機械(`voiceMode`/`voiceEnabled`)やViewModel APIは変更しない(Viewの表現だけ)。
- max 8 iterations。スクショ検証で同じ問題が3回続いたらユーザーに相談。
